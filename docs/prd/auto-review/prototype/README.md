# 消化率の状態見本

[handling-ring.html](./handling-ring.html) をブラウザで開く。ユーザー指定の「静かな円形表示」を一つの方向として具体化した見本で、複数案からの採用判断を代行するものではない。

初回待機・未判定・指摘なし・0/5・3/5・5/5・指摘追加・更新待ち・部分確認済み（全体は更新待ち）・校閲中・停止・確認待ちを切り替えられる。右下を押すと見本のパネルを開閉する。パネル内の操作は対応件数だけを変え、閲覧は消化に数えない。

確認する点は、指摘なしと全件対応の区別、未対応と初回待機の区別、古い率が最新結果のように見えないこと、執筆面を邪魔しないこと。細部の見え方は実装時の作者による視覚確認で調整する。

この見本は外部送信・実校閲・保存・自動起動・採否履歴の永続化を実装しない。ボタンは状態の確認用であり、本番の起動操作ではない。既存FABのモノクロ・大きさ・動作の制約に合わせ、外部素材・ライブラリ・再配布する原典は含めない。
