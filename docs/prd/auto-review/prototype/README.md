# 消化率の状態見本

[handling-ring.html](./handling-ring.html) をブラウザで開く。ユーザー指定の「静かな円形表示」を一つの方向として具体化した見本で、複数案からの採用判断を代行するものではない。

中央にminaosiのロゴを置き、外周のボーダーは指摘数に対する対応済みの割合だけを表す。初回待機・指摘なしは全件対応と同じ、切れ目のない全周表示にする。ツールチップや未判定の点線など、別の状態表示は置かない。

見本用の入力で対応済み件数と指摘数を変え、割合を確認できる。指摘数0は初回待機・指摘なしの全周表示に相当する。右下を押すと見本のパネルを開閉する。パネル内の操作は対応件数だけを変え、閲覧は消化に数えない。

確認する点は、割合が外周に反映されること、全周に切れ目がないこと、執筆面を邪魔しないこと。細部の見え方は実装時の作者による視覚確認で調整する。

この見本は外部送信・実校閲・保存・自動起動・採否履歴の永続化を実装しない。ボタンは状態の確認用であり、本番の起動操作ではない。既存FABのモノクロ・大きさ・動作の制約に合わせ、外部素材・ライブラリ・再配布する原典は含めない。
